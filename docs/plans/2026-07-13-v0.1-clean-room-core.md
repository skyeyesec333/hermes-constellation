# Hermes Constellation v0.1 Clean-Room Core Implementation Plan

> **For Hermes:** Execute task-by-task with strict TDD and independent review before publication.

**Goal:** Build a local, clean-room, standalone Hermes plugin and reusable Python core that proves the trusted Constellation loop without copying any private vault content.

**Architecture:** Markdown and preserved source files are canonical. A minimal Python core handles versioned records, safe vault initialization, source ingestion, candidate review/promotion, SQLite FTS5 retrieval, and token-aware research receipts. A thin Hermes plugin registers namespaced tools and commands against that shared service layer. All examples are fictional; no private vault is read during implementation.

**Tech stack:** Python 3.12, Pydantic 2, PyYAML, SQLite FTS5, pytest, standard-library argparse/pathlib/hashlib/json/tempfile.
